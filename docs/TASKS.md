## Harbor runs with real models

Each task run once through Harbor 0.25.0 with the built-in terminus-2 agent (`python -m alegen.modelrun`, see its docstring for what differs from a plain `harbor run` on this host: locally built images, no network in the container during the agent phase, model calls made by the Harbor process through a local streaming shim). Task content and time limits unchanged; `max_turns=150`. Ten tasks: the hardest level of every family (seven level-4 tasks, and the level-3 task for amplicon_16s, md_system_repair and somatic_tn). The agent is text-only: it cannot look at screenshots. Tokens are the sums over all turns as reported by the provider (the agent resends the whole history every turn, so most input tokens are cache hits). Models reached through OpenRouter are pinned to one named provider per model (OpenRouter serves most of these models from many providers, often with quantised weights). `cost estimate` is what LiteLLM computes from its price table, not the amount billed: for kimi-k3 the table has a price for cached input, so the estimate should be close to the bill; for gemini-3.8-flash it has none, so cached input is counted at the full input price and the figure is an upper bound.
